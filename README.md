# ContactManagementSysytem
A Contact Management System developed using Java, applying Object-Oriented Programming (OOP) principles and Java Swing for the graphical user interface (GUI).
The application provides contact management functionality, including adding, editing, deleting, and searching for contacts. It allows users to enter contact details such as name, email, and phone number, and displays contacts in a table.
The GUI is currently under development, with the main contact form and contacts table implemented and connected to the application logic.

Technologies Used:
- Java
- Object-Oriented Programming (OOP)
- Java Swing
